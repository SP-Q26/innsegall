“Unidentified developer” after download?

Preferred: InnsegallInstaller.zip (Developer ID signed + notarized). Unzip · open Innsegall Installer.app.

If you used the legacy .command file or the release is not up yet · open Terminal · paste:

curl -fsSL https://innsegall.com/scripts/innsegall-alpha-install.sh | bash

If you already downloaded Innsegall-Install.command:

  1. In Downloads, right-click the file → Open → Open again (one-time).
  2. Or: System Settings → Privacy & Security → Open Anyway after the first blocked try.
  3. Or in Terminal: xattr -d com.apple.quarantine ~/Downloads/Innsegall-Install.command then double-click.
