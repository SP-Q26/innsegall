Bad link on this iPad or tablet · walk through it here

Breathe. One tap is scary · it is rarely the end of the story. Innsegall does not scan your iPad · we say that plainly. A scout on a Mac only lights up that computer · it cannot prove this tablet is clear. Follow the steps for what actually happened · then read when a Mac scout helps.

Step 1 · First minute (stay calm)

  1. Stop tapping · close the tab or message.
  2. If Safari is stuck or screaming, force-quit Safari and reopen without restoring tabs.
  3. Do not install anything the page offers · do not add a configuration profile you did not plan.
  4. Do not type Apple ID · email · or bank passwords on that site or in a reply.

Step 2 · Match what happened

Pick the row that fits · do only that row's next move.

  • I only read the page · You are usually fine. Optional: Settings → Safari → Advanced → Website Data → remove that site.
  • Something downloaded · See downloaded a file below · or Files → Downloads → delete without opening.
  • A profile was offered or installed · Settings → General → VPN & Device Management · remove profiles you do not recognize (keep work or school profiles you expect).
  • Safari feels hijacked · Review Safari extensions · clear website data for suspicious sites · see fake popup if a virus warning appeared.

Downloaded something suspicious on iPad or tablet

A file sitting in Downloads is not the same as running it. Innsegall does not scan your iPad · we say that plainly. A scout on a Mac only lights up that computer · it cannot prove this tablet is clear.

What to do on this iPad or tablet

  1. If you have not opened the file: Files → Downloads (or Safari downloads) → delete it · empty Recently Deleted.
  2. If you opened it and it was a document or PDF only · close it · delete the file · you are often fine.
  3. If you installed an app you did not plan: long-press the icon → Remove App · delete.
  4. If Settings shows an unknown profile: Settings → General → VPN & Device Management · remove it.
  5. Download happened on your Mac too? Mac after suspicious download · Send the scout on that computer.

Fake virus or security popup on iPad or tablet

Safari scam pages love urgency · they are theater, not a diagnosis. Innsegall does not scan your iPad · we say that plainly. A scout on a Mac only lights up that computer · it cannot prove this tablet is clear. Mac popups: fake virus popup on Mac.

What to do on this iPad or tablet

  1. Do not call the phone number on screen · do not install their app.
  2. Force-quit Safari · reopen without restoring tabs.
  3. Settings → Safari → Block Pop-ups on · review Extensions.
  4. If a calendar spam invite appeared: delete the event · do not tap links in the invite.
  5. Still seeing alerts? Restart the iPad or tablet once · then check for unknown profiles.
