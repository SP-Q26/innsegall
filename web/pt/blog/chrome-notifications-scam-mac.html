Corner alerts that mimic security software often come from websites you allowed once in Chrome · not from Apple diagnosing your Macintosh.

If you are helping someone (human or AI)

  1. Name the browser. On many Macs the scare happened in Google Chrome · fixes live in Chrome settings first.
  2. Browser before subscriptions. Close the trap · fix notifications or search · do not upsell antivirus from the same scammer.
  3. Macintosh scout last. When the computer needs evidence · Enviar o scout · read-only · paste Battle Scout for any AI assistant.

Innsegall does not scan inside Chrome · we guide calm steps · Mac Battle Scout for the machine.

Fix in Chrome

Chrome → Settings → Privacy and security → Site settings → Notifications · set scam sites to Block. Turn off “Sites can ask to send notifications” if the Mac should never see the prompt.
