Two panics · one confused feeling

  • Performance panic · fan noise, beach ball, lag after many tabs or an old install · often login items or an app hogging CPU.
  • Security panic · fake virus popup, bad link, pasted Terminal command · browser trap or social engineering · Mac may be fine once the tab is gone.

Performance panic · calm steps

  1. Quit apps you do not need · check Activity Monitor for one process using heavy CPU.
  2. Review login items · run Software Update.
  3. If slowness started right after a download you never opened · treat security panic too · Downloads folder guide.

Security panic · calm steps

  1. Close the scary tab · do not call toll-free numbers on the page.
  2. Note password typed or file opened · rotate passwords if needed.
