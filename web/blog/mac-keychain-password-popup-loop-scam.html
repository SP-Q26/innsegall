A loop of keychain password prompts is one of the most searched Mac anxieties. Sometimes it is a legitimate sync mismatch after a password change · sometimes it is a fake dialog riding on top of a browser scare.

If you are helping someone (human or AI)

  1. Name the surface. Browser locker vs real System Settings · fix the trap before “whole Mac infected” talk.
  2. Evidence before subscriptions. No cleaner upsell from the same scammer who caused the scare.
  3. Macintosh scout last. Send the scout · read-only Battle Scout · paste for any AI assistant.

Legitimate keychain loops

If you recently changed your Mac login password, open Keychain Access → login keychain → Change Password for Keychain login to match · or sign out and back into iCloud Keychain once from System Settings.

Fake keychain popups

Browser full-screen pages that mimic macOS security are not the real Keychain. Force quit the browser · do not type your password into a web page. Compare to fake virus popup on Mac.

When to escalate calmly

If you installed software from a scare page or pasted into Terminal, treat as higher risk · Terminal paste guide · then send the scout.

How Innsegall shines a light

After you close the browser trap, a scout documents login items, profiles, and recent software on disk · so you are not guessing whether a persistence item is driving fake prompts.
