Las alertas en la esquina de la pantalla que imitan a macOS o al antivirus son uno de los principales problemas de la comunidad de Reddit y Apple. La mayoría son notificaciones push web que permitiste una vez, no malware en el sistema operativo.

Reparar en Safari

Safari → Configuración → Sitios web → Notificaciones · seleccione sitios sospechosos → Denegar o Eliminar. Desactive "Permitir que los sitios web soliciten permiso para enviar notificaciones" si nunca desea recibir el mensaje.
