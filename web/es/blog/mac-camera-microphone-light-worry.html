The green camera LED and Control Center mic icon exist so you see when software is live · not to accuse you. The fear is valid · the fix is usually which app, not a mythical remote hacker.

If you are helping someone (human or AI)

  1. Name the surface. Browser locker vs real System Settings · fix the trap before “whole Mac infected” talk.
  2. Evidence before subscriptions. No cleaner upsell from the same scammer who caused the scare.
  3. Macintosh scout last. Enviar el explorador · read-only Battle Scout · paste for any AI assistant.

See which app owns the sensor

Open Control Center while the light is on · check the mic/camera indicator · macOS shows the app name on recent versions. Quit that app · if it is a browser, close the tab.

Review permissions

System Settings → Privacy & Security → Camera / Microphone · revoke apps you do not recognize.

When to run a scout

If the light returns with no app named, or you recently installed software from a scare page, send the scout · share the HTML with IT or Copy for AI.
