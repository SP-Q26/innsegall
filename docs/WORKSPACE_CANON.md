# Workspace canon · one Innsegall folder

**Goal:** One git clone you edit · one Vercel project · no drift between Desktop, `~/innsegall`, and `~/SPQ/innsegall`.

## Canonical working copy (operator)

| Location | Role |
|----------|------|
| **`~/Desktop/innsegall`** | Preferred daily folder (when Cursor has Desktop access) |
| **`~/innsegall`** | Same repo if Desktop is a copy or symlink · keep in sync with Desktop |
| **`~/SPQ/innsegall`** | Legacy nest inside SPQ · **do not edit** unless merging into canon · archive or delete after sync |

## Sort & clean (run from your working folder)

```bash
cd ~/Desktop/innsegall   # or ~/innsegall
npm run audit:git        # identity · origin sync · workspace · before commit
npm run clean:workspace  # optional · .smoke + dist
npm run audit:workspace
npm run sync:blog-brand
node scripts/sync-site-chrome.mjs
npm run audit:brand-stack
npm run audit:swarm
```

Safe to delete anytime (regenerated by tests):

- `.smoke/` · local smoke + self-test artifacts
- `node_modules/` · `npm ci`
- `dist/` · build output if present
- `.DS_Store` · macOS junk (gitignored)

Never commit:

- `.env.local` · `web/.env.local` · `.vercel/`

## Cursor + Desktop

If the agent reports **Operation not permitted** on Desktop:

1. **System Settings → Privacy & Security → Full Disk Access** → enable **Cursor**
2. Or open the folder in Cursor: **File → Open Folder** → `~/Desktop/innsegall`
3. Or work in `~/innsegall` and symlink:  
   `ln -sfn ~/innsegall ~/Desktop/innsegall`

## Git identity (this repo only)

```bash
npm run setup:git-identity
npm run check:git-identity
```

## After cleaning duplicates

1. Push from **one** clone only (`main` → `github.com/SP-Q26/innsegall`)
2. Vercel deploys from that push (root directory: `web` in project settings)
3. Retire the stale clone: `rm -rf ~/SPQ/innsegall` only after you confirm Desktop/home has all commits
